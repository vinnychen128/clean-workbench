# 清洗项目 · 使用说明

> 本地数据清洗台 — 默认全程本地处理，拖入文件即可开洗。

## 一键启动

```bash
./scripts/start.sh
```

启动后自动拉起：

- **后端**：`127.0.0.1:8321`
- **前端**：`http://localhost:5173`

## 五步走

| 步骤 | 操作 | 说明 |
|------|------|------|
| **1. 拖入文件** | 打开前端，将 CSV / Excel / PDF 拖入上传区 | 支持多种文件格式，文件仅在本机内存中处理，不上网 |
| **2. 体检（EDA）** | 点击「开始体检」，系统自动检测 9 类数据问题 | 如：缺失值、重复行、类型不一致、异常值等 |
| **3. 确认配方** | 根据体检结果，勾选需要的清洗规则，生成「配方」 | 配方可导出、可重放；修改后重新确认 |
| **4. 执行清洗** | 点击「确认并执行」，系统按配方清洗数据 | 清洗前会二次确认；清洗过程可中断（人工门） |
| **5. 导出结果** | 清洗完成后，一键导出四件套：干净数据 + 报告 + 问题明细 + 配方 | 支持 CSV、Excel、ODS、PDF、JSON、SQL 等格式 |

## 常见问题

### 文件打开后显示乱码

- **原因**：文件编码不是 UTF-8，系统默认按 UTF-8 读取导致乱码。
- **解决**：用记事本 / 文本编辑器打开文件 → 另存为 → 编码选 UTF-8 → 保存后重新拖入。

### 大文件处理慢

- **原因**：文件超过 50MB 时，系统需要更多内存和时间进行全量扫描。
- **建议**：大文件建议先在 Excel/CSV 中分片（如按行拆分），分批清洗后再合并。

### 某些格式不支持

- 目前支持：CSV（UTF-8）、XLSX、ODS、PDF（文本型）、JSON。
- 不支持：`.docx`、`.xls`（97-2003）、图片、加密 PDF。
- 如需支持新格式，可联系开发方添加检测器。

### 清洗后想反悔怎么办

- 系统**不覆盖原始文件**，始终保留原件和清洗后的副本。
- 如果清洗结果不满意，可以重新调整配方，重新确认 → 重新执行。
- 也可从 `backend/data` 目录恢复之前的清洗结果。

### 前端打不开 / 白屏

1. 确保 `start.sh` 已正常运行，后端端口 8321 可访问。
2. 浏览器开发者工具查看是否有报错（按 F12）。
3. 尝试更换浏览器（Chrome / Edge / Firefox）。
4. 检查防火墙是否拦截了 5173 端口。

## 数据隐私声明

- **所有数据仅在本机处理**，不会上传到任何服务器或第三方。
- 清洗主链路不调用 AI / 大模型；AI 辅助**默认关闭**，由你决定是否开启，开启后仅发送列的形态（列名 + 列级统计），不发送数据值。
- 原始文件不会被修改或删除，清洗结果以独立副本保存。
